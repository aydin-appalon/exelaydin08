01 · Что такое Excel

Программа, которая считает за тебя

Microsoft Excel — это электронная таблица. Данные записываются в ячейки, а ячейки объединены в строки и столбцы. У каждой ячейки есть адрес: например, B2 — это столбец B и строка 2.

Главная идея Excel — формулы. Ты пишешь, что нужно посчитать, и результат обновляется сам, как только меняются исходные числа. Не нужно пересчитывать вручную.

02 · Для каких задач

Где применяют Excel

  • Личный бюджет — доходы, расходы, накопления на цель
  • Учёт и склад — списки товаров, остатки, продажи
  • Учёба — оценки, статистика, обработка данных лабораторных работ
  • Бизнес-отчёты — итоги по месяцам, прибыль, графики для руководства
  • Планирование — расписания, списки дел, трекеры привычек

04 · Функции

МАКС, МИН и СЧЁТ

Эти функции быстро отвечают на вопросы: «Какой самый большой результат?», «Какой самый маленький?», «Сколько у меня записей?». Данные — та же таблица продаж.

450

МАКС — наибольшее значение в диапазоне.

200

МИН — наименьшее значение.

4

СЧЁТ — сколько ячеек содержат числа.

05 · Функции

ЕСЛИ — функция с условием

Самая популярная логическая функция. Excel проверяет условие и выбирает один из двух ответов.

Синтаксис: =ЕСЛИ(условие; если_да; если_нет)

Хорошо

У яблок продано 300 — условие верно, поэтому ответ «Хорошо». Для сливок (200) получилось бы «Мало».

Так можно автоматически ставить оценки, отмечать долги, находить выполненный план.

06 · Функции

ВПР — поиск по таблице

ВПР ищет значение в первом столбце таблицы и возвращает данные из той же строки. Удобно, когда нужно найти цену по названию или оценку по фамилии.

Синтаксис: =ВПР(что_ищем; таблица; номер_столбца; 0)

450

Нуль в конце означает точное совпадение. В новых версиях Excel есть более удобная замена — ПРОСМОТРX.

07 · Функции

СЧЁТЕСЛИ и СУММЕСЛИ

Считают не всё подряд, а только то, что подходит под условие. Например, только продажи больше 250.

3

СЧЁТЕСЛИ — сколько ячеек удовлетворяют условию (300, 450 и 300).

1 050

СУММЕСЛИ — сумма только подходящих ячеек.

08 · Полезные приёмы

Горячие клавиши и советы

Alt + = автосумма выделенных ячеек
F4 закрепить адрес в формуле ($A$1)
Ctrl + Z отменить действие
Ctrl + Shift + L включить фильтр
Ctrl + D скопировать формулу вниз
Ctrl + S сохранить файл

Протяни за маленький квадрат в углу ячейки — формула сама скопируется на соседние строки.

Итоги

Что нужно запомнить

  • Excel — таблицы, которые автоматически считают и анализируют данные
  • Любая формула начинается со знака =
  • Базовый набор: СУММ, СРЗНАЧ, МАКС, МИН, СЧЁТ
  • Для решений: ЕСЛИ, ВПР, СЧЁТЕСЛИ, СУММЕСЛИ
  • Навык пригодится в школе, вузе и на любой работе
